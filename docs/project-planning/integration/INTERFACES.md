# কোন data কে লেখে, কে ব্যবহার করে

**উৎসের নিয়ম** — School হলো tenant, campus তার ভেতরের scope। এক person-এর একাধিক school membership থাকতে পারে। একবারে একটি membership দিয়ে session চলে। School বদলালে নতুন session হয় এবং আগের school-এর cached context সরতে হয়। Platform product চালু করে, Identity actor-এর access নির্ধারণ করে, আর প্রতিটি domain নিজের record বদলায়। Cross-module reference হবে ID দিয়ে। অন্য module-এর table-এ সরাসরি read, write বা join করার বদলে owner-এর interface বা event ব্যবহার হবে। [Doc 03](../03-system-module-and-data-map.md) · [Doc 04](../04-roles-and-permissions.md) · Blueprint পৃ. ১২–১৫, ২৪–২৬, ৩২, ৪৬, ৭৫–৭৬।

**নাম পড়ার নিয়ম** — নিচের event নামগুলির উৎস Blueprint পৃ. ১২–১৩, ৩৬। এগুলি সহ সব actual API, type, table ও package-এর অবস্থা **Repository verification pending**। **Proposed** লেখা shape ও sample এই তিন team-এর planning decision নেওয়ার জন্য। Backend পেলে প্রকৃত নাম, source path ও version পাশাপাশি বসবে।

## একজন student প্রথমবার ক্লাসে বসলে

**Proposed fixture।** School A-তে School Management চালু। তার উত্তর campus-এর Registrar একটি synthetic CSV আনলেন। Row `r17`-এ school-এর student number `A-017`, guardian contact, grade 6, section নীল ও school calendar-এর শুরুর দিন আছে। Academics আগেই ঐ school, campus ও year-এর section ID দিয়েছে। School B-তেও একই section নাম ও একই student number রাখা যায়। Isolation test-এ দুই school-এই একই product, campus-ভিত্তিক Registrar ও নিজের row দিয়ে সফল import দেখাতে হবে। তারপর A-র session-এ B-র record চাওয়া হবে। Product test-এ কেবল entitlement বদলাবে।

**API ও event delivery।** Blueprint পৃ. ৩৫–৩৬ অনুযায়ী versioned API-তে state change-এর `Idempotency-Key` একই body-তে আগের ফল দেয়, ভিন্ন body-তে reject হয়। Stale record version-এ current state সহ conflict আসে, error shape problem details। তারিখ school-এর civil date, instant UTC। Owner data change ও outbox event একই transaction-এ রাখে। Delivery অন্তত একবার, subscriber event ID দিয়ে repeat বাদ দেয়। ব্যর্থ delivery replay করা যায়। Envelope-এর Proposed fields `eventId, eventType, eventVersion, schoolId, recordId, recordVersion, occurredAt`। প্রযোজ্য হলে product ও effective date-ও থাকবে। Event-এ প্রয়োজনীয় ID/fact থাকে। Child-এর নাম, custody document বা marks sheet পাঠানো যাবে না। Consumer বর্তমান scope আবার দেখবে। [Doc 03, Integration rules](../03-system-module-and-data-map.md) · INT-001/002, requirement 14.2.7, DVL-006।
